The fastest way to see what kittymux does is the demo. It opens its own kitty window with its own configuration and state, a sample session and a few fake agents in different states. Your real configuration is never read or changed, and closing the window removes it.

<Callout type="info" title="Before you start">
  You need kitty 0.48 or later on Linux, plus `jq`, `python3`, `fzf` and `git`. kitty 0.49.2 adds
  clickable file references, pane title bars and the native resize arrow. See [Install and
  update](/docs/users/install-and-update) for the full list.
</Callout>

## Set up in four steps

<Steps>

<Step>

### Try the demo

```sh
git clone https://github.com/KitsuneKode/kittymux ~/kittymux
~/kittymux/bin/kittymux demo
```
Press `ctrl+alt+b` for the deck and `ctrl+alt+y` to jump to the agent that is waiting. Press `ctrl+space`, then `?`, to see leader mode. Close the window when you are done.

</Step>

<Step>

### Install

```sh
~/kittymux/install.sh
```
The installer checks its dependencies, backs up `kitty.conf` and adds a few `include` lines. It never overwrites a file of yours. Add `--leader` to also turn on the tmux-style prefix.

</Step>

<Step>

### Check the install

```sh
kittymux doctor
```
`doctor` lists anything that is off and says how to fix it: a missing dependency, a remote control socket that is too open, a shortcut that clashes with your window manager, or a kitty that was updated while it kept running.

</Step>

<Step>

### Add agent hooks

```sh
kittymux hooks --install
```
This merges Claude Code's status hooks into `~/.claude/settings.json`, after making a backup. The hooks let an agent say "tool finished, still working" and "session ended", which keeps a quiet screen from being mistaken for "finished". Other agents work from the screen alone. `kittymux hooks --remove` takes exactly those entries back out.

</Step>

</Steps>

## Your first five minutes

Do these in a normal kitty window after installing.

1. **See every key.** Press `ctrl+alt+/`. Type a word to search, such as `pane` or `deck`. One `esc` closes it.
2. **Start an agent.** Press `ctrl+alt+shift+o`, then `c` for Claude, `x` for Codex, `d` for Devin. Hold `shift` with the letter to start it in a split instead of a new tab.
3. **Read the bar.** A spinner means working. `!` means it is asking you something. `⊘` means it hit a usage limit. `✓` means it finished while you were elsewhere. See [Agent status](/docs/users/agent-status).
4. **Jump to the one that needs you.** Press `ctrl+alt+y`. Repeat to go to the next one, longest-waiting first.
5. **Look without leaving.** Right-click a tab for its peek card, press `ctrl+alt+shift+q` for a quick look at the agent that has waited longest, or press `ctrl+alt+b` for the deck. See [Peek, deck and panel](/docs/users/peek-deck-and-panel).
6. **Split, then join.** Press `ctrl+alt+enter` to split a pane below. Press `ctrl+alt+shift+j` in another tab to move all of its panes into the tab you pick. See [Tabs and panes](/docs/users/tabs-and-panes).
7. **Save the workspace.** Press `ctrl+alt+shift+s`. After a crash, `kittymux sessions restore last` brings it back, and each agent asks before resuming its conversation. See [Sessions and restore](/docs/users/sessions-and-restore).

## More to try in the demo

| Tab        | Try                                          | You should see                                                    |
| ---------- | -------------------------------------------- | ----------------------------------------------------------------- |
| panes      | `ctrl+alt+e`                                 | A digit on every pane. Press one and that pane takes focus.       |
| panes      | `ctrl+alt+shift+y`, then a digit             | The focused pane swaps with that one.                             |
| panes      | `ctrl+alt+d`                                 | The focused pane becomes its own tab.                             |
| panes      | `ctrl+alt+shift+c`                           | A title bar on every pane. Drag one onto the bar to move a split. |
| file-refs  | `ctrl+shift+click` on `src/app.py:42:7`      | Your editor opens at line 42. A made-up path opens nothing.       |
| scrollback | `ctrl+alt+PgUp` and `ctrl+alt+PgDn`          | The view moves a page back and forward.                           |
| any        | Right-click a tab                            | A peek card with the tab's state, panes and the tail of its screen. |

<Callout type="warn" title="Run commands inside the demo">
  `kittymux screenshot`, `kittymux dim` and similar commands act on the kitty they are started
  from. Start them from a shell pane inside the demo, or they will act on your real window.
</Callout>
