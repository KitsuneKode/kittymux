kittymux is a set of small pieces on top of kitty. Each section below names a task and points to the page that covers it.

## Know where each tab is

- A vertical bar with one row per tab: the agent's logo, the title, the branch, the pane count and one state glyph. Colours come from your own theme. See [The tab bar](/docs/users/the-tab-bar).
- A folder line under each tab, so tabs without a visible directory stay distinguishable. A stable colour per project, and extra emphasis on tabs that look alike.
- A slim rail, a hidden mode, four edges and named presets. Drag the edge to resize.

## Look at a tab without switching to it

- Right-click a tab for a **peek card**: its state, the question it is asking, branch, folder, panes and the tail of its screen.
- Press `ctrl+alt+b` for the **deck**: every tab across every session, with live preview, search, hover and keys.
- Press `ctrl+alt+shift+b` for the **docked panel**: the deck as an always-visible column on Wayland.

See [Peek, deck and panel](/docs/users/peek-deck-and-panel).

## Rearrange panes and tabs

- Join all the panes of a tab into another tab as splits, keeping their shape.
- Turn a pane into its own tab, move it to a tab you pick, swap panes, number them and jump by digit.
- Drag a pane's title bar onto a tab, the bar or another pane.

See [Tabs and panes](/docs/users/tabs-and-panes).

## Keep agents in view

- Five states, decided from the screen and hooks and shown the same way everywhere. See [Agent status](/docs/users/agent-status).
- One desktop notification per event, an inbox for everything, and a key that jumps to the agent that has waited longest. See [Notifications and inbox](/docs/users/notifications-and-inbox).
- Spawn agents, pick any of them from one list, reopen one you closed, fan one prompt out to several in separate worktrees and see what each changed. See [Launch and find agents](/docs/users/launch-and-find-agents).

## Get your work back

- Save a workspace and restore it with each agent window asking to resume its own conversation. A journal records every agent session as it runs. See [Sessions and restore](/docs/users/sessions-and-restore).

## Make it yours

- Turn each optional piece on or off, pick a layout and keep your own shortcuts. See [Customization](/docs/users/customization) and [Your own shortcuts](/docs/users/your-own-shortcuts).

### Planned

Not built. The docs say so wherever they mention it.

| Feature | What it does |
| --- | --- |
| Side sheet beside the bar | A sheet with more about a tab. Not built; the peek card and the deck cover the need today. |
| Sheet that opens on hover | Not possible from the bar itself, because kitty sends it no idle mouse motion; it can only live inside a sheet or the panel. |
| Workspace switcher | A recent-first list of sessions and OS windows with their agent states, as one key. The deck and pick already list every tab of every OS window. |
| Rename a session | Rename a session and keep its tab titles, saved file and journal in step. |
| Type into several panes | One keystroke stream into every pane of a tab, like tmux synchronize-panes. |
| Documentation site | The docs in this folder rendered by a TanStack Start and Fumadocs app. |

## How kittymux compares

|                 | kittymux                         | [cmux](https://github.com/manaflow-ai/cmux) | [herdr](https://terminaltrove.com/herdr/) |
| --------------- | -------------------------------- | ------------------------------------------- | ----------------------------------------- |
| What it is      | A configuration layer for kitty  | Its own macOS terminal, based on Ghostty    | A multiplexer that runs inside a terminal |
| Platform        | Linux (Wayland and X11)          | macOS                                       | Cross-platform                            |
| Your terminal   | Stays kitty                      | Replaces it                                 | Any                                       |
| Background daemon | None                           | An app                                      | One binary                                |
| Agent state     | Hooks, plus the screen           | Notifications and hooks                     | Process detection                         |

Choose kittymux if you already live in kitty and do not want a second multiplexer between you and your terminal. tmux stays the right tool for remote work.
