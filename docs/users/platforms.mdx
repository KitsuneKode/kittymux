### Window manager keys

Hyprland, as configured by HyDE's scrolling layout, takes `ctrl+alt` plus `a`, `s`, `f`, `c`, `x`, `p`, `w`, `m`, the arrow keys, `=` and `-`. kittymux avoids those chords, and a unit test pins the list. `kittymux doctor` checks your live Hyprland binds. Hyprland sees a global chord before kitty does, so a chord it owns never reaches kitty. See [Your own shortcuts](/docs/users/your-own-shortcuts).

## What kitty does and does not send

These were measured on kitty 0.49.2, and they shape what kittymux can offer.

| Question                                                  | Answer                                                                                                                                                  |
| --------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Does idle mouse motion over the tab bar reach Python?     | No. In a real-pointer test, none of eight idle moves arrived; only press and release did. Hover cannot open anything from the bar itself.               |
| Can the pointer over the bar be something other than a hand? | No. kitty chooses the shape in C for the whole bar and ignores shape requests there.                                                                |
| Does kitty hit-test split borders in a single-pane tab?   | No. The native resize arrow only appears in tabs with two or more panes.                                                                                |

The first row is why the right-click [peek card](/docs/users/peek-deck-and-panel) exists, and why a sheet that opens on hover is [planned](/docs/developer/roadmap) only in a form that lives inside the sheet or the panel.

## Agent CLIs

Status is read from each agent's screen, so it depends on what the interface prints. Markers were checked against real sessions on the author's machine. Versions drift, and a tool that rewords its prompts needs a one-line change.

| Agent                                       | Screen markers                                                                                                                       | Hooks                                |
| ------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------ |
| Claude Code                                 | Tested: working, permission prompt and usage limit.                                                                                  | `kittymux hooks --install`           |
| Codex CLI                                   | Tested: working and usage limit. Some status lines match by shape and have not been seen live.                                       | `notify`, calling `mux-status`       |
| Devin                                       | Tested: working, idle prompt. Whether subagent footers mean running subagents is unverified.                                         | None                                 |
| OpenCode                                    | The idle screen was checked live. The working marker follows the documented hint.                                                    | None                                 |
| Gemini CLI, Cursor Agent, Amp, Antigravity | Patterns follow each tool's documented hints. Not verified against live sessions.                                                    | None                                 |
| Factory `droid`                             | "No active subscription found" reads as limited (seen live). Working and permission markers are not verified.                         | None                                 |
| grok, qwen, kimi, goose, kilo, vibe, junie, auggie | Logo plus hooks or title activity only.                                                                                       | Optional                             |
| aider, crush                                | No readable markers, so hooks or title activity only.                                                                                | Optional                             |

To add or check an agent, see [Contribute](/docs/developer/contribute#add-an-agent).

## Things that depend on your environment

- **Remote control socket.** The pickers and the CLI need `allow_remote_control` and `listen_on`. kittymux only talks to sockets you own. See [Install and update](/docs/users/install-and-update#recommended-remote-control-settings).
- **Fonts.** Brand logos live in a bundled icon font. kitty loads fonts only at start, so restart once after the first install.
- **Notification daemons.** Tested with dunst on Hyprland. Mako, swaync, KDE and GNOME are untested. The Jump to it action needs a daemon with action support.
- **The Quickshell sample.** It follows the documented inbox contract and is untested, because Quickshell is not installed on the author's machine.
