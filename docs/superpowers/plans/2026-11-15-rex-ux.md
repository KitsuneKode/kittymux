# Rex-inspired kittymux UI Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Reliable attention, consistent graphical Usage/Inbox, and discoverable scoped pane controls.

**Architecture:** Reuse the existing meter/event models, Cairo/Pango painter, graphics transport and Kitty actions. Three independent components can be implemented concurrently; the parent owns panel integration, selection, docs and qualification.

**Tech Stack:** Python, Kitty kittens/graphics/remote control, Cairo/Pango, shell Xvfb rigs.

**Spec:** `docs/superpowers/specs/2026-11-15-rex-ux-design.md`

## Global Constraints

- Never edit main, restart/focus live Kitty, or touch unrelated worktrees.
- Live palette only; bounded resources; cell fallback; `deckpx` switch controls pixel views.
- No new daemon, provider poller, global chord, or automatic agent input.
- Preserve private/mute/snooze policy and guard every close.
- Kitty 0.50 docks are gated on the running target's version.
- Rigs use private state/config/socket directories, `socket-only` and an other-Kitty tripwire.

## Review Focus

- A new event arrives while a selected event is being expanded/dismissed: identity stays fixed.
- A prompt is long/unbroken or the viewport is short: details and actions remain reachable.
- Quota data is missing/stale and multiple accounts/pools differ: never present unknown as zero or combine unrelated quotas.
- Graphics fail or a pixel view changes/resizes: remove old placements and retain a usable fallback.
- The pane's focus/tab changes while its controls are open: commands still target the parent and guarded close is preserved.

## Task 2: Pure pixel panel renderer

Files: new `python/kittymux_panelpx.py`, `tests/test_panelpx.py`.

Interface: `usage(data, history, selected, palette, width, height, *, now=None, details=False, scroll=0, hover=None, resources=None)` and `inbox(events, filter, selected, palette, width, height, *, now=None, expanded=None, scroll=0, hover=None, undo=False, resources=None)` return a `Rendered(surface, hits, content_height, selected_bounds)` value. Hits are `(kind, value, x, y, width, height)` in image pixels; action kinds `provider`, `filter`, `select`, `expand`, `jump`, `dismiss`, `key`. Values are provider indexes, event IDs, filter strings or key tokens. `selected_bounds` is `(top, bottom)` in unscrolled content coordinates. Reuse existing `kittymux_deckpx.Painter/Resources` and normalized meters, cleaning every untrusted string. The parent handles transport and input.

- [x] Test used-to-remaining conversion, no fabricated quota for token counters, long/empty/stale/error events, hit bounds and both themes at narrow/wide sizes; observe failures.
- [x] Implement provider cards and expandable message pills using the existing painter/tokens, bounded layouts and explicit reset/pace/freshness labels.
- [x] Render synthetic PNGs for the parent to inspect, run renderer tests.

## Task 3: Optional pane control dock

Interface: `kittymux pane-controls [show|hide|toggle]`. Run inside Kitty targets its own pane, outside requires explicit unambiguous target. Native top window dock only after verifying target Kitty >=0.50. Reuse existing scoped split/zoom/move/closeguard actions. Do not introduce a chord.

- [x] Test version refusal, invalid parent IDs, own-socket scope, target preservation after focus changes and guarded close; observe failures.
- [x] Implement keyboard/pointer action strip and CLI lifecycle; no timer/poller.
- [x] Validate with a private Kitty and real events, with a failing control and other-Kitty tripwire.

## Task 4: Integrate pixel views and stable expanded selection

Files: `python/sidebar-kit.py`, `python/kittymux_inboxview.py`, existing handler tests, install module list and relevant docs.

Event expansion is keyed by ID; Enter jumps and `d`/Space expands; expansion never acknowledges. Preserve event selection by ID during refresh. Add equivalent cell detail support. Reuse shared transport/caches; clear spinner/fade when changing view.
