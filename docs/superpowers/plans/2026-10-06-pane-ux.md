# Pane UX implementation plan

Goal: Native pane rearrangement, truthful compact split indicators, useful previews and merged-state captions, with measured performance work.
Architecture: Kitty owns geometry, actions and selection UI. Pure deck helpers own bounded cached maps, layout coverage and preview formatting. Existing merged agent resolver remains authoritative.
Spec: 2026-10-06-pane-ux-design.md (approved in conversation).

## Constraints
- Work in this isolated worktree. No live restart, focus movement or unrelated changes.
- Config templates and published docs change together; version gates and theme-derived tokens remain.
- Synthetic fixtures only. Smoke rigs use private sockets and compare other instances' window counts.
- No new timer globals or extra draw-path file reads. Silence never implies completion.

## Tasks
- [x] Native pane controls: test action dispatch and closed targets; add a choice kitten using kitty's choose, move_window, layout_action and swap_with_window APIs; bind the free ctrl+alt+shift+semicolon chord; smoke with real keys, confirm counts and geometry.
- [x] Reliable bar overview: test three stacked/unequal pane coverage and minimum-width count fallback; cache immutable geometry, draw count before folder text and keep the small map only when coverage is complete; preserve folder-off behavior; verify dark/light wide/narrow screenshots.
- [x] Peek/deck: test title/status budgets, numbered diagram and pane selection; display wrapped title/path and preview identity, select panes by digit/click; debounce hover requests while invalidating stale generations; inspect rendered cards and hover smoke.
- [x] Captions/performance: test merged statuses surviving narrow captions and hostile text; reserve state mark in optional captions; benchmark cached maps and scanner extraction; only retain optimizations with parity evidence and measured improvement.
- [ ] Docs/review/integration: update README, users pages, feature YAML and generated table; run full Python/shell/install/reload and affected smoke checks; independent whole-change review; preserve unrelated work; integrate/reload according to authorization and report actual verification.

## Review focus
- Three stacked panes must never look like only two; tiny/unequal panes need a count fallback.
- Hidden sidebar must not create invisible persistent keyboard capture; use a visible native picker.
- A pane disappearing during selection must change nothing else.
- Slow and ABA hover requests must not publish an old pane preview.
- No status drift, duplicate timers or text reads stored beyond existing bounded evidence.

## Execution record
Baseline: 895 tests pass with private-socket permissions and kitty environment removed. Initial sandbox run failed on socket binding and inherited kitty targeting, not source defects.
Ruling: use kitty's native one-action choice picker instead of persistent pane mode. It is always visible, including with a hidden bar, and exits after each action or Escape; it has no timer state and delegates all movements to kitty. The same directional/rotate/swap/equalize controls remain available.
Live WM: no Ctrl+Alt+Shift (modmask 13) bindings. Prefix absent from kitty config search. Real key validation remains required.

User extension (final accepted answer): Mod+N toggles a persistent Agents-and-Usage panel from any app. Keep the original agent picker CLI and add its Usage utility entry, opening a separate kitty window. Usage styling follows T3 Code quota hierarchy while chrome and meter surfaces follow the live kitty theme. Local data remains default; network remains opt-in.
Performance ruling: retain native full-screen extraction for status parity with wrapped lines and 14 nonempty logical lines; do not substitute 14 physical lines. Bounded geometry caching and single-flight/debounced previews are the supported gains.
