# Audit — launcher, journal, secrets (2026-10-02)

Scope: everything added since the 2026-10-01 audit — sessions/resume/journal, the inbox, spawn / pick / reopen / mute / snooze, the rofi theme, the bar insights — plus a repo-wide sweep.
Method: `gitleaks` over the whole history and the tree; `shellcheck -S warning` over all shell; greps for shell injection, unsafe deserialisation, TLS opt-outs and destructive commands; hostile-input tests;
and real-kitty rigs. No `bandit`/`semgrep` on the author's machine — the Python review was by reading plus targeted tests. Not covered: other compositors, macOS, live provider APIs.

| # | Finding | Severity | Status |
|---|---|---|---|
| 1 | A real token prefix and a key-shaped literal were committed in a test fixture (copied from a process listing) | high (secret in a public repo) | History amended and force-pushed with a lease; token must be rotated by its owner. `tests/test_no_secrets.py` + CI `gitleaks` prevent a repeat. |
| 2 | `pick` put raw window titles into menu rows. Any program can set a title: a newline forged rows and shifted the indexes a menu returns (what you see ≠ what runs); ESC / bidi overrides spoofed text | medium | Fixed: every field through `clean_text`; rows with control characters refused at the menu boundary. Tests with hostile titles. |
| 3 | Snooze was a window user variable — settable by any program in that window, so an agent could silence its own "needs you" popup | medium | Fixed: private per-kitty file, capped at 30 days, absurd/forged values ignored. |
| 4 | `kittymux uninstall --purge` ran `rmtree` on `$KITTYMUX_STATE` unchecked (`KITTYMUX_STATE=$HOME` would delete the home) | medium (misconfiguration → data loss) | Fixed: refuses `/`, home and above, symlinks, directories that are not recognisably ours. |
| 5 | A key-launched `spawn` followed "the focused kitty": on a machine with several kittys (or a test rig next to a working session) it acted on the wrong one | medium (a rig opened fake agents in the author's live kitty and polluted the real journal) | Fixed: a command acts on the kitty it was started from; focus-following only outside every kitty. Rigs now confine discovery and carry a cross-kitty tripwire. Strays cleaned. |
| 6 | `lib/mux.sh` created the state dir's parent with the default umask (`mkdir -p -m` applies the mode to the deepest directory only) | low | Fixed. |
| 7 | `mux-agents.sh` neutralised tab/newline in rows but not ESC / bidi | low | Fixed. |
| 8 | The recommended `allow_remote_control yes` lets any program print an escape sequence that controls kitty | high (setup) | Recommendation changed to `socket-only` (proved in `smoke_socket.sh`); `doctor` warns on `yes` and on a `/tmp` socket. |
| 9 | The agent journal and session files record commands with their flags | info | 0600; printed output is redacted (`redact_argv`); documented in SECURITY.md ("don't pass secrets as flags"). |
| 10 | `mux-send.sh` passed the typed text to `send-text` after the options: text starting with `-` (a markdown bullet) was rejected as an unknown kitty option, and could be read as one (verified in a private kitty) | low | Fixed: `--` before the text. |

Considered and left alone: the usage collectors (credentials go to curl on stdin, not argv; no redirect following; fixed https URLs); `hooks --install` (backs up, touches only our entries); `notify-send` call (`--`, markup-escaped,
icon from our table); the project picker (lists the author's own directories; user-initiated).
